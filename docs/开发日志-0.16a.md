# Dota 2 录像复盘开发日志

## 0.16a（2026-10-27）

### 本版内容

- 完善录像地图要素接口：提供录像读取到的防御塔、兵营、遗迹、肉山、魔方、商店和双生传送门，以及 7.41 地图目录中的莲花池、野怪营地等地图标记。
- 补齐防御塔、近战/远程兵营、遗迹的阵营和路线识别；地图上使用对应图标展示建筑，并区分阵营。
- 使用游戏内小地图素材展示防御塔、兵营、遗迹、肉山、魔方、传送门和真假眼。真假眼采用不同图标与名称区分。
- 将地图底图、昼夜着色、视野估算、轨迹、兵线、眼位、英雄和目标建筑拆成独立图层，保证地图目标图标在顶层可见。
- 根据录像中的肉山与魔方实体坐标定位目标；结合 7.41 底图中的坑位图形校准图标显示中心，原始录像坐标保留用于数据记录。
- 增加昼夜切换显示及随时间变化的昼夜色调；英雄标准视距圈作为估算结果随时间轴显示。
- 展示兵线位置及野怪营地状态候选，包括清野与堆叠判断；候选结果保留采样证据与缺失说明。
- 后端接口返回地图要素、地图观察和覆盖情况，支持前端读取录像解析结果。

### 数据与实现说明

- 地图目标位置优先取自录像实体；莲花池和野怪营地等稳定地图点使用 gem-dota 的 7.41 地图目录。
- 地图机制范围标注为 7.41f。录像与 OpenDota 仅能确认主版本时，子版本依据发布时间窗口推定，不视为录像内精确版本证明。
- 地图底图为 7.41 风格示意底图。昼夜视野圈是标准范围估算，不代表实际战争迷雾或地形遮挡。
- 清野和堆叠显示为采样推断候选；实体缺失可能由解析器可见性和采样间隔造成，不等同于确定的击杀或拉野记录。

### 项目能力概览

- 导入 Dota 2 `.dem` 录像并以 SQLite 保存复盘数据。
- 按游戏时间查看英雄位置、眼位、事件、经济、BP 和地图观察。
- 提供桌面复盘界面、只读 Web 地图界面、离线 HTML 报告和 CSV 导出。
- 可同步 Valve 官方英雄改动记录并在本地检索。

### 本版验证记录

- 本地地图 API 已核对当前录像中的肉山与魔方坐标返回值。
- 仓库包含现有单元与 Web 接口测试；本次版本整理未重新运行测试套件。
