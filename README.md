# Dota 2 录像复盘

面向 Dota 2 比赛录像的本地复盘工具。项目围绕 `.dem` 录像解析英雄轨迹、眼位、开雾、神符、BP 与经济等数据，并提供比赛浏览、趋势分析和证据型复盘能力。

## 项目状态

当前项目处于本地开发和验证阶段。GitHub 仓库现阶段仅用于展示项目说明，**目前不执行部署**，也不提供可公开访问的在线服务。

## 计划中的部署方案（暂不执行）

未来如进入部署阶段，建议按以下方案实施：

1. **运行环境**：使用受支持的 Linux LTS 主机或云服务，固定 Python 与 Node.js 版本；通过锁定依赖和构建产物保证版本可复现。
2. **应用构建**：安装 Python 依赖；在 `frontend/` 安装 npm 依赖并运行生产构建；由 FastAPI 提供 API，并托管构建后的前端静态文件。
3. **数据库**：使用受控访问的 MySQL 实例，先在备份和回滚方案就绪后执行数据库结构迁移；应用仅使用最小权限账号连接数据库。
4. **配置与密钥**：通过部署平台的环境变量或密钥管理服务提供数据库连接、模型服务等配置；不将 `.env`、密码、API 密钥或比赛数据提交到 Git 仓库。
5. **网络与安全**：在反向代理后提供 HTTPS；限制管理入口和数据库网络访问；配置身份认证、访问控制、请求日志及密钥轮换。
6. **发布与运维**：先在隔离的预发布环境完成功能、迁移和备份恢复检查，再采用可回滚的版本发布；配置健康检查、监控、日志保留和数据库备份。

以上仅为后续部署的规划说明。是否部署、目标平台、域名、认证方式、数据迁移及运维配置均需在部署阶段另行确定；**当前阶段不执行部署、云资源创建、数据库迁移或公开服务发布**。

## 当前本地开发方式

本地开发所需源码与配置模板保留在开发工作区。开发者可在准备好的 Python 环境中安装 `requirements.txt`，并在 `frontend/` 安装 npm 依赖后启动 API 和前端开发服务器。具体命令、环境变量和数据准备以本地源码及 `.env.example` 为准。

比赛录像、数据库、缓存和密钥属于本地或受控运行数据，不应上传到公开仓库。
